# Estrategia histórica 2020–hoy

- Backfill primero UAF y CMF por mayor granularidad y volumen.
- SCJ: recorrer páginas históricas y conservar cargos, resolución, recurso y pago.
- SUSESO: registro estructurado; separar entidad fiscalizada de persona/directivo cuando aplique.
- SP: combinar registro/fichas/resoluciones; declarar degradación si la fuente granular bloquea automatización.
- Cada año pasa por validación de cobertura antes de marcarse completo.
- 2019 y anteriores se conservan sólo como contexto de reincidencia cuando una resolución 2020+ los cite o cuando se ejecute un backfill opcional.
